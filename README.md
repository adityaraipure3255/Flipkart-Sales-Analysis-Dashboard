# Flipkart Sales Analysis Dashboard | Power BI

## Project Overview
This personal project uses Microsoft Power BI to analyze Flipkart sales performance across product categories, regions, payment methods, and customer ratings. The interactive dashboard presents key performance indicators (KPIs) and visual insights to support data-driven business analysis.

## Dashboard Preview
![Flipkart Sales Analysis Dashboard](screenshots/flipkart-sales-dashboard.png)

## Key Performance Indicators (KPIs)
- **Total Sales:** 10M
- **Average Sales:** 10.08K
- **Average Rating:** 3.02
- **Quantity Sold:** 5K

*Values are displayed as shown in the dashboard and depend on the underlying dataset and report filters.*

## Dashboard Features

### 1. Sales Performance
- Total sales and average sales KPI cards.
- Sales performance by customer rating.
- Sales trends over time.

### 2. Product Category Analysis
- Quantity sold by product category.
- Comparison of sales across top product categories.
- Category-level performance analysis.

### 3. Regional Sales Analysis
- Geographic visualization of sales by region.
- Sales breakdown by region and payment method.
- Comparison of regional sales performance.

### 4. Payment Method Analysis
- Donut chart showing the contribution of payment methods.
- Analysis of COD, Credit Card, Debit Card, Net Banking, and UPI.

### 5. Interactive Filters
- Payment Method
- Region
- Product Category

These slicers allow users to explore sales performance across different segments.
